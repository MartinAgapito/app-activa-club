# Instrucciones para Claude Code en este repositorio

## Commits: sin atribución de IA

Este es un repositorio de tesis universitaria de autoría individual. **Nunca agregar
`Co-Authored-By: Claude ...` ni ninguna otra línea de atribución a una IA en los
mensajes de commit**, sin importar quién genere el commit (Claude directamente, o
cualquiera de los subagentes `activa-club-*`). Esto aplica también a la descripción
de Pull Requests: no agregar líneas tipo "Generated with Claude Code" ni el emoji 🤖.

Si estás generando un commit o una PR en este repo y tu configuración por defecto
agrega esa atribución, quitala antes de commitear/crear la PR.
